# MOBIE

MOBIE는 영화와 책을 기록하고, 별점과 장르를 기준으로 추천 목록을 확인할 수 있는 웹 서비스입니다.

## 주요 기능

- 영화/책 기록 추가
- 기록 목록 조회
- 상세 보기
- 기록 수정/삭제
- 영화/책 필터링
- 별점순 정렬
- 별점 4점 이상 추천 목록
- 장르별 추천 필터

## 실행 방법

별도 설치 없이 브라우저에서 `index.html`을 열면 실행할 수 있습니다.

```text
index.html
```

데이터는 브라우저의 `localStorage`에 저장됩니다.
