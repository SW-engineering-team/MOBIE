# MOBIE 프로젝트 WBS

## 1. WBS 작성 목적

본 WBS는 영화/책 추천 기록 웹 서비스인 **MOBIE**의 개발 작업을 단계별로 분해하여 정리한 문서이다.  
과제에서 요구하는 요구사항 분석, 설계, 구현, 테스트, 품질 관리, 최종 산출물 정리 과정을 체계적으로 수행하고 있음을 증빙하기 위해 작성하였다.

## 2. 작업 분해 구조

## 3. 핵심 흐름

```text
기획/요구사항
  -> 화면 및 데이터 설계
  -> 기능 구현
  -> 테스트 및 품질 관리
  -> AI 활용 분석과 최종 보고서 작성
```

## 4. 프로세스 증빙 방식

- 회의록은 `docs/meetings/`에 날짜별로 작성한다.
- 요구사항과 설계 결과는 `docs/requirements.md`, `docs/design.md`에 정리한다.
- 구현 및 수정 과정은 Git 커밋으로 남긴다.
- 테스트 결과와 품질 개선 내용은 `docs/test-report.md`에 기록한다.
- 바이브코딩 과정에서 사용한 AI 프롬프트와 결과는 `docs/ai-prompts.md`에 기록한다.
- 최종 보고서에는 WBS, 간트차트, 회의록, 커밋 기록을 프로세스 적용 증빙으로 활용한다.
