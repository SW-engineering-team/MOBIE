# 3차 회의록 - 2026-05-24

## 1. 회의 목적

이번 회의에서는 2차 회의에서 정리한 핵심 기능과 요구사항을 바탕으로 **화면 구조와 데이터 구조를 설계**하였다.  
구현에 바로 들어가기 전에 사용자가 어떤 흐름으로 기록을 추가하고, 목록을 탐색하며, 추천 항목을 확인할지 와이어프레임 형태로 정리하는 것을 목표로 하였다.

---

## 2. 이전 회의 내용 확인

2차 회의에서는 MOBIE의 핵심 기능을 다음과 같이 확정하였다.

- 영화/책 기록 추가
- 기록 목록 조회
- 상세 보기
- 기록 수정/삭제
- 별점 또는 장르 기반 간단 추천

이번 회의에서는 위 기능을 실제 화면과 데이터 항목으로 연결하였다.

---

## 3. 논의 안건

### 3.1 화면 구조 설계

MOBIE의 화면은 사용자가 기록을 쉽게 추가하고, 기존 기록을 빠르게 탐색할 수 있도록 단순한 구조로 설계하기로 하였다.

- 홈/목록 화면
- 기록 추가/수정 화면
- 상세 보기 화면
- 추천 목록 화면

### 3.2 데이터 구조 설계

기록 하나를 하나의 콘텐츠 객체로 보고, 영화와 책을 같은 데이터 구조에서 관리하기로 하였다.  
유형 필드를 통해 영화와 책을 구분하면 필터링과 목록 표시가 단순해진다고 판단하였다.

### 3.3 와이어프레임 작성

구현 전 화면 배치를 먼저 정리하여, 이후 바이브코딩 과정에서 AI에게 명확한 UI 요구사항을 전달할 수 있도록 하였다.

## 4. 화면 구조

### 4.1 홈/목록 화면

홈 화면은 사용자가 가장 자주 보는 화면이므로 기록 목록, 필터, 정렬, 추천 이동 버튼을 한곳에 배치한다.

```text
+--------------------------------------------------+
| MOBIE                                            |
| 영화와 책을 기록하고 추천 목록을 확인하는 공간       |
+--------------------------------------------------+
| [기록 추가]                                      |
|                                                  |
| 필터: [전체] [영화] [책]      정렬: [최신순/별점순] |
+--------------------------------------------------+
| 제목        유형    장르     별점    상태          |
| 인셉션      영화    SF       5      완료          |
| 데미안      책      소설     4      보는 중        |
| 듄          영화    SF       4      보고 싶음      |
+--------------------------------------------------+
| [추천 목록 보기]                                  |
+--------------------------------------------------+
```

### 4.2 기록 추가/수정 화면

기록 추가와 수정은 같은 입력 폼을 사용하고, 저장 버튼의 동작만 구분하기로 하였다.

```text
+--------------------------------------------------+
| 기록 추가 / 수정                                  |
+--------------------------------------------------+
| 제목        [                              ]       |
| 유형        ( ) 영화   ( ) 책                      |
| 장르        [                              ]       |
| 별점        [1] [2] [3] [4] [5]                   |
| 감상 상태   [보고 싶음 / 보는 중 / 완료]             |
| 한 줄 감상평 [                              ]       |
| 추천 여부   [ ] 추천함                             |
| 추천 이유   [                              ]       |
+--------------------------------------------------+
| [저장] [취소]                                     |
+--------------------------------------------------+
```

### 4.3 상세 보기 화면

상세 화면에서는 기록의 전체 내용을 확인하고, 수정 또는 삭제로 이동할 수 있게 한다.

```text
+--------------------------------------------------+
| 제목: 인셉션                                      |
| 유형: 영화                                        |
| 장르: SF                                          |
| 별점: 5                                           |
| 상태: 완료                                        |
+--------------------------------------------------+
| 한 줄 감상평                                      |
| 꿈과 현실의 경계가 인상적인 영화                   |
+--------------------------------------------------+
| 추천 여부: 추천함                                  |
| 추천 이유: 몰입감 있는 전개와 독특한 설정            |
+--------------------------------------------------+
| [수정] [삭제] [목록으로]                           |
+--------------------------------------------------+
```

### 4.4 추천 목록 화면

추천 목록은 별점 4점 이상인 항목을 기본으로 보여주고, 장르를 선택하면 해당 장르의 높은 별점 작품을 보여준다.

```text
+--------------------------------------------------+
| 추천 목록                                         |
+--------------------------------------------------+
| 추천 기준: 별점 4점 이상                           |
| 장르 선택: [전체 / SF / 소설 / 에세이 / 드라마]      |
+--------------------------------------------------+
| 제목        유형    장르     별점    추천 이유       |
| 인셉션      영화    SF       5      몰입감 있음      |
| 데미안      책      소설     4      다시 읽고 싶음    |
+--------------------------------------------------+
| [목록으로]                                        |
+--------------------------------------------------+
```

## 5. 데이터 구조

기록 데이터는 다음 구조로 설계하였다.

```json
{
  "id": "record-001",
  "title": "인셉션",
  "type": "movie",
  "genre": "SF",
  "rating": 5,
  "status": "completed",
  "review": "꿈과 현실의 경계가 인상적인 영화",
  "recommended": true,
  "recommendReason": "몰입감 있는 전개와 독특한 설정",
  "createdAt": "2026-05-24",
  "updatedAt": "2026-05-24"
}
```

### 데이터 필드 설명

| 필드              | 설명                             |
| ----------------- | -------------------------------- |
| `id`              | 각 기록을 구분하기 위한 고유값   |
| `title`           | 영화 또는 책 제목                |
| `type`            | 콘텐츠 유형, `movie` 또는 `book` |
| `genre`           | 장르                             |
| `rating`          | 1~5점 별점                       |
| `status`          | 감상 상태                        |
| `review`          | 한 줄 감상평                     |
| `recommended`     | 추천 여부                        |
| `recommendReason` | 추천 이유                        |
| `createdAt`       | 기록 생성일                      |
| `updatedAt`       | 기록 수정일                      |

---

## 6. 주요 결정 사항

- 영화와 책은 별도 데이터 구조로 나누지 않고, `type` 필드로 구분하기로 하였다.
- 기록 추가와 수정은 동일한 폼을 재사용하기로 하였다.
- 추천 목록은 초기 버전에서 별점 4점 이상을 기준으로 구성한다.
- 장르 기반 추천은 별점 기준 추천을 보완하는 방식으로 설계한다.
- UI는 복잡한 메뉴 구조보다 목록 중심의 단순한 구조로 구현한다.
- 상세 보기에서는 감상평과 추천 이유를 함께 확인할 수 있도록 한다.
