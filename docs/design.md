# 화면 및 데이터 구조 설계

## 1. 화면 구조 설계

**MOBIE**는 영화와 책을 기록하고 관리하는 서비스이므로 사용자가 기록을 추가하고, 목록을 조회하며, 상세 내용을 확인하고 수정·삭제할 수 있는 흐름을 중심으로 구성하였다. 또한 별점 기반 추천 기능을 제공하기 위해 추천 목록 화면을 별도로 설계하였다.

화면은 크게 **기록 목록 화면(메인 화면), 기록 추가 화면, 상세 보기 화면, 추천 화면**으로 구성하였다. 기록 목록 화면에서는 저장된 콘텐츠를 한눈에 확인할 수 있으며 영화/책 필터링과 별점순 정렬 기능을 제공한다. 기록 추가 화면에서는 제목, 유형, 장르, 별점, 감상 상태, 감상평 등의 정보를 입력하여 새로운 기록을 등록할 수 있다. 상세 보기 화면에서는 개별 콘텐츠의 정보를 확인하고 수정 및 삭제를 수행할 수 있으며, 추천 화면에서는 별점이 높은 콘텐츠와 장르별 추천 목록을 제공하도록 설계하였다.

### 예상 화면 흐름

```text
기록 목록 화면 (메인 화면)
 |
 +-- 기록 추가 화면
 |
 +-- 상세 보기 화면
 |    +-- 수정
 |    +-- 삭제
 |
 +-- 추천 화면
```

### 1.1 기록 목록 화면(메인 화면)

사용자가 저장한 영화 및 책 기록을 조회하는 화면이다. 전체 목록 확인, 유형별 필터링, 별점순 정렬 기능을 제공한다.

주요 구성 요소는 다음과 같다.

- 영화/책 필터 버튼
- 별점순 정렬 기능
- 기록 카드 목록
- 기록 추가 버튼
- 상세 보기 이동
- 추천 화면 이동

### 1.2 기록 추가 화면

새로운 영화 또는 책을 등록하는 화면이다.

입력 항목은 다음과 같다.

- 제목
- 유형: 영화 / 책
- 장르
- 별점
- 감상 상태
- 한 줄 감상평
- 추천 여부
- 추천 이유

### 1.3 상세 보기 화면

선택한 콘텐츠의 상세 정보를 확인하는 화면이다.

제공 정보는 다음과 같다.

- 제목
- 유형
- 장르
- 별점
- 감상 상태
- 감상평
- 추천 여부
- 추천 이유

추가 기능은 다음과 같다.

- 수정
- 삭제

### 1.4 추천 화면

별점 기반 추천 콘텐츠를 제공하는 화면이다.

주요 기능은 다음과 같다.

- 별점 4점 이상 콘텐츠 추천
- 장르 선택 기능
- 장르별 추천 목록 제공

## 2. 데이터 구조 설계

서비스 구현을 위해 영화 및 책 기록 정보를 저장하는 데이터 구조를 설계하였다. 영화와 책은 별도 구조로 나누지 않고 하나의 공통 데이터 구조로 관리하며, `type` 필드를 통해 영화와 책을 구분한다.

| 필드명            | 자료형  | 설명                       |
| ----------------- | ------- | -------------------------- |
| `id`              | Integer | 고유 식별자                |
| `title`           | String  | 콘텐츠 제목                |
| `type`            | String  | 영화 또는 책               |
| `genre`           | String  | 콘텐츠 장르                |
| `rating`          | Integer | 1~5점 별점                 |
| `status`          | String  | 보고 싶음 / 보는 중 / 완료 |
| `review`          | String  | 한 줄 감상평               |
| `recommended`     | Boolean | 사용자의 추천 여부         |
| `recommendReason` | String  | 추천 이유                  |

### 데이터 예시

| id  | title                  | type | genre  | rating | status  | review                    | recommended | recommendReason                          |
| --- | ---------------------- | ---- | ------ | ------ | ------- | ------------------------- | ----------- | ---------------------------------------- |
| 1   | 인터스텔라             | 영화 | SF     | 5      | 완료    | 인상 깊은 영화였다.       | true        | 우주와 시간에 대한 설정이 몰입감 있었다. |
| 2   | 해리포터와 마법사의 돌 | 책   | 판타지 | 5      | 완료    | 몰입감이 뛰어났다.        | true        | 세계관이 흥미롭고 다시 읽고 싶다.        |
| 3   | 기생충                 | 영화 | 드라마 | 4      | 보는 중 | 사회적 메시지가 흥미롭다. | true        | 주제 의식이 강해서 추천할 만하다.        |
| 4   | 라라랜드               | 영화 | 로맨스 | 3      | 보는 중 | 음악과 연출이 인상 깊다.  | false       | 추천 목록 기준에는 포함하지 않는다.      |

```json
{
  "id": 1,
  "title": "인터스텔라",
  "type": "영화",
  "genre": "SF",
  "rating": 5,
  "status": "완료",
  "review": "인상 깊은 영화였다.",
  "recommended": true,
  "recommendReason": "우주와 시간에 대한 설정이 몰입감 있었다."
}
```

## 3. 설계 결과

이번 회의에서는 요구사항을 바탕으로 서비스의 화면 구조와 데이터 구조를 설계하였다. 사용자가 콘텐츠를 등록하고 관리하는 기본 흐름을 정의하였으며, CRUD 기능과 필터링, 정렬, 추천 기능을 지원할 수 있도록 화면 간 이동 구조를 구성하였다.

또한 데이터 구조를 명확히 정의하여 이후 데이터베이스 설계와 프론트엔드 구현 과정에서 일관성 있게 활용할 수 있도록 기반을 마련하였다.

## 4. 상세 와이어프레임

### 4.1 기록 목록 화면(메인 화면)

사용자가 저장한 영화/책을 확인하는 화면이다.

```text
+-----------------------------+
|           MOBIE             |
+-----------------------------+
| [전체] [영화] [책]          |
|                             |
| 정렬 ▼ (별점 높은순)        |
+-----------------------------+
| 별점 5                      |
| 인터스텔라                  |
| 영화 | SF | 완료            |
| "인상 깊은 영화였다."       |
+-----------------------------+
| 별점 5                      |
| 해리포터와 마법사의 돌      |
| 책 | 판타지 | 완료          |
| "몰입감이 뛰어났다."        |
+-----------------------------+
|                             |
|                    [+ 추가] |
+-----------------------------+
```

기능은 다음과 같다.

- 전체 목록 조회
- 영화 필터
- 책 필터
- 별점순 정렬
- 상세 페이지 이동
- 추가 버튼

### 4.2 기록 추가 화면

새로운 영화/책을 등록할 수 있는 화면이다.

```text
+-----------------------------+
|      기록 추가              |
+-----------------------------+
| 제목                        |
| [___________________]       |
|                             |
| 유형                        |
| ( ) 영화  ( ) 책            |
|                             |
| 장르                        |
| [_________]                 |
|                             |
| 별점                        |
| [1] [2] [3] [4] [5]         |
|                             |
| 감상 상태                   |
| ▼ 보고 싶음                 |
|                             |
| 한 줄 감상평                |
| [___________________]       |
|                             |
| 추천 여부 [ ]               |
| 추천 이유                   |
| [___________________]       |
|                             |
| [저장]                      |
+-----------------------------+
```

기능은 다음과 같다.

- 영화/책 등록
- 별점 입력
- 상태 선택
- 감상평 입력
- 추천 여부 및 추천 이유 입력

### 4.3 상세 보기 화면

기록의 상세 내용을 확인하는 화면이다.

```text
+-----------------------------+
| 인터스텔라                  |
+-----------------------------+
| 유형 : 영화                 |
| 장르 : SF                   |
| 별점 : 5                    |
| 상태 : 완료                 |
|                             |
| 감상평                      |
| --------------------------- |
| 인상 깊은 영화였다.         |
| --------------------------- |
|                             |
| 추천 여부 : 추천            |
| 추천 이유                   |
| 우주와 시간에 대한 설정이   |
| 몰입감 있었다.              |
|                             |
| [수정]    [삭제]            |
+-----------------------------+
```

기능은 다음과 같다.

- 상세 정보 조회
- 수정
- 삭제

### 4.4 추천 화면

추천 콘텐츠를 모아보는 화면이다. 기본적으로 별점 4점 이상인 항목을 추천 목록으로 보여주며, 장르를 선택하면 해당 장르의 높은 별점 콘텐츠를 확인할 수 있다.

```text
+-----------------------------+
|        추천 콘텐츠          |
+-----------------------------+
| 추천 기준: 별점 4점 이상    |
| 장르 선택 ▼                 |
|                             |
| 별점 5                      |
| 인터스텔라                  |
| 영화 | SF                   |
| 우주와 시간에 대한 설정이   |
| 몰입감 있었다.              |
+-----------------------------+
| 별점 5                      |
| 해리포터와 마법사의 돌      |
| 책 | 판타지                 |
| 세계관이 흥미롭다.          |
+-----------------------------+
```

기능은 다음과 같다.

- 별점 4점 이상 추천 목록
- 장르별 추천 필터
- 추천 이유 확인

---

## 5. 추천 기준 정리

추천 화면에서 사용하는 추천 기준은 다음과 같이 정리한다.

- 기본 추천 기준은 `rating >= 4`이다.
- 장르를 선택한 경우, 선택한 장르에 속하면서 `rating >= 4`인 항목을 보여준다.
- `recommended`는 사용자가 직접 추천 여부를 표시한 값이다.
- 추천 화면의 표시 기준은 별점이며, 추천 여부와 추천 이유는 상세 설명 정보로 활용한다.
