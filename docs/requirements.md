# MOBIE 요구사항 분석

## 핵심 기능

### 1. 영화/책 기록 추가

사용자는 영화 또는 책 기록을 새로 추가할 수 있다. 기록 추가 시 다음 정보를 입력한다.

- 제목
- 유형: 영화 / 책
- 장르
- 별점
- 감상 상태: 보고 싶음 / 보는 중 / 완료
- 한 줄 감상평
- 추천 여부

### 2. 기록 목록 조회

사용자는 등록한 영화와 책 기록을 목록으로 확인할 수 있다.

- 전체 목록 보기
- 영화/책 유형별 필터링
- 별점순 정렬

### 3. 상세 보기

사용자는 개별 기록의 상세 정보를 확인할 수 있다.

- 제목 확인
- 감상평 확인
- 추천 이유 확인

### 4. 수정/삭제

사용자는 기존 기록을 수정하거나 삭제할 수 있다.

- 기록 내용 수정
- 기록 삭제

### 5. 간단한 추천 기능

사용자는 기록된 항목을 바탕으로 추천 목록을 확인할 수 있다.

- 별점 4점 이상인 항목을 추천 목록으로 따로 표시한다.
- 장르 선택 시 해당 장르의 높은 별점 작품을 추천한다.

이 기능 범위는 CRUD, 필터링, 정렬, 추천 구조를 모두 포함하므로 소프트웨어 공학 프로세스 적용 결과를 보고서에 설명하기에 적절하다.

## 주요 데이터 항목

| 항목         | 설명                       |
| ------------ | -------------------------- |
| 제목         | 영화 또는 책의 이름        |
| 유형         | 영화 / 책                  |
| 장르         | 콘텐츠 장르                |
| 별점         | 사용자가 부여한 점수       |
| 감상 상태    | 보고 싶음 / 보는 중 / 완료 |
| 한 줄 감상평 | 사용자의 간단한 기록       |
| 추천 여부    | 추천 목록 포함 여부        |

## 기능 요구사항

- 사용자는 영화 또는 책 기록을 추가할 수 있다.
- 사용자는 제목, 유형, 장르, 별점, 감상 상태, 감상평을 입력할 수 있다.
- 사용자는 등록된 기록 목록을 조회할 수 있다.
- 사용자는 영화/책 유형에 따라 기록을 필터링할 수 있다.
- 사용자는 별점순으로 기록을 정렬할 수 있다.
- 사용자는 별점이 높은 항목을 추천 목록으로 확인할 수 있다.
- 사용자는 장르를 선택하여 해당 장르의 높은 별점 작품을 추천받을 수 있다.
- 사용자는 기존 기록을 수정할 수 있다.
- 사용자는 기존 기록을 삭제할 수 있다.

## 비기능 요구사항

- 사용자가 쉽게 입력할 수 있는 직관적인 화면을 제공해야 한다.
- 입력값 누락 시 오류 메시지를 제공해야 한다.
- 기록 목록은 한눈에 구분 가능해야 한다.
- 추천 기준은 명확하게 표시되어야 한다.
- 코드 구조는 유지보수가 가능하도록 컴포넌트 단위로 분리되어야 한다.

## 요구사항 우선순위

| 우선순위 | 항목           | 설명                                                  |
| -------- | -------------- | ----------------------------------------------------- |
| 높음     | 기록 추가      | 서비스의 핵심 기능이며 모든 기능의 출발점이다.        |
| 높음     | 기록 목록 조회 | 사용자가 저장한 콘텐츠를 확인하기 위한 기본 기능이다. |
| 높음     | 수정/삭제      | 기록 관리 앱으로서 필수적인 CRUD 기능이다.            |
| 중간     | 영화/책 필터링 | 콘텐츠 유형별 탐색을 지원한다.                        |
| 중간     | 별점순 정렬    | 사용자가 선호 작품을 빠르게 찾을 수 있게 한다.        |
| 중간     | 추천 목록      | 별점 기반으로 추천 콘텐츠를 따로 확인할 수 있게 한다. |
| 낮음     | 장르 기반 추천 | 추천 기능을 확장할 수 있는 추가 기능이다.             |

## 요구사항 분석 결과

MOBIE는 영화와 책을 기록하는 단순한 목록 앱에서 출발하지만, 별점, 감상 상태, 필터링, 추천 기능을 포함하여 사용자가 자신의 콘텐츠 소비 취향을 관리할 수 있도록 한다.

초기 구현 범위는 CRUD와 필터링, 별점 기반 추천에 집중한다. 이후 시간이 허용될 경우 장르 기반 추천이나 통계 기능을 추가하여 서비스의 완성도를 높일 수 있다.
